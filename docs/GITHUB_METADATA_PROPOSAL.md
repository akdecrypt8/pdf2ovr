# GitHub repository metadata proposal

For manual review only. This document does not change GitHub repository
settings.

## Proposed About description

> Experimental Python toolkit for inspecting and editing selected ERDAS HFA/EANT annotation overlays, with PDF extraction and GeoPDF georeferencing.

This wording deliberately says **selected** overlays and does not imply that
general PDF-to-OVR conversion or universal ERDAS compatibility is supported.

## Proposed topics

- `erdas-imagine`
- `ehfa`
- `hfa`
- `eant`
- `geopdf`
- `gis`
- `reverse-engineering`

These topics reflect the current implementation: HFA/EHFA container parsing,
selected EANT inspection/editing, GeoPDF metadata and coordinate tools, and
format investigation. `reverse-engineering` is descriptive of the evidence-
driven format work, not a claim of a complete proprietary format specification.
