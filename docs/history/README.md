# Historical validation reports

The files in this directory preserve test and validation reports written
during earlier development milestones. Their commands, counts and references
are historical records for the code state at that time; they are not the test
results for the current release-preparation tree. In particular, early reports
used two external OVR examples that are not distributed with the current
repository. Current CI uses the synthetic fixtures documented in
[`../TEST_FIXTURES.md`](../TEST_FIXTURES.md).

No standalone `PHASE1_TEST_REPORT.md` existed in the inspected source archive.
The Phase 1 implementation history was consolidated into the root
[`CHANGELOG.md`](../../CHANGELOG.md); no missing Phase 1 test report has been
invented.
